> 给队友：不需要装任何东西，解压 → 双击 → 浏览器自动打开。

**版本**：最终版（2026-10-04 构建）　|　**构建产物**：`dist/`（Vite 6 + Vue 3.5）

## 零、这一版有什么（先看这个）

底部 Tab 只有 **3 个**（音疗 / 开始练 / 我的），其他页面从这几个进去，或者直接在地址栏敲 `地址后面加 #/xxx`。

| 页面 | 地址 | 干什么 |
|---|---|---|
| 首页 | `#/` | 拳种选择（底部「开始练」Tab） |
| **跟练** | `#/train` | 摄像头做八式，做对自动拨响古琴（**核心功能**，从首页点「开始练」进） |
| 音疗 | `#/sound` | 音色与音层入口（底部「音疗」Tab） |
| 琴谱库 | `#/sound/library` | 44 首曲库（目前 2 首有音源，其余标「待补」） |
| 琴谱工坊 | `#/workshop` | 曲库与定弦管理 |
| 五调弧线 | `#/arc` | 12 分钟三阶段弧线播放 |
| **文化内核实验室** | `#/culture` | 五音 / 子午流注 / 节气食养 / 九种体质 / 和香，一张处方点到四套硬件 |
| 我的 | `#/me` | 设置、打卡记录（底部「我的」Tab） |
| 打卡记录 | `#/record` | 历史练习数据 |
| 身体数据 | `#/me/body-data` | 录入身体数据看推荐（**首次进去是空态**） |
| 设置 | `#/me/settings` | 摄像头 / 画面 / 语音 |
| 七步问卷 | `#/onboarding-v2` | 首次进入的偏好采集（新版宣纸插画卡） |
| 图文指南 | `#/guide` | 八式动作说明 |
| 骨架采集台 | `#/pose-lab` | 调试用：看识别骨架原始数据 |
| 原型壳 | `#/prot` | 设计原型静态页（调试用） |

两个使用上的注意：

1. **摄像头只在 `localhost` 或 `https` 下能用**。手机同 WiFi 访问要找聪哥拿证书（`dist/xianyang-ca.crt` + `dist/setup-cert.html`），别自己折腾。
2. `#/culture` 里的「体质」「食养」「和香」是**文化内容数字化 + 可插拔硬件适配演示**，不是医疗建议，界面里也不出现任何疗效表述。
3. `#/pose-lab`、`#/prot` 是调试页，正式演示不用管。

## 一、怎么跑起来（3 步）

### 第 1 步 · 解压

把 `弦养-最终版交付包_20261004.zip` 解压到**任意目录**（路径里有中文也没关系）。

### 第 2 步 · 双击 `启动预览.bat`

黑窗口会跳出日志，**别关它**（关了就断服务）。

### 第 3 步 · 浏览器已自动打开

地址是 `http://localhost:5173`

> **卡在「没找到 Node.js」？**
> 去 https://nodejs.org 下载 **LTS 版**安装，一路默认即可（约 30MB）。
> 装完再双击 `启动预览.bat`。

## 二、你要做什么：走用户路径

**背景**：这是一个「对着摄像头做八段锦，做对动作就自动拨响古琴」的 H5。
你的任务是**像真实用户一样从头走一遍**，记录哪里卡住了、哪里看不懂。

### 用户路径总览（8 步）

| 步 | 做什么 | 关注什么 |
|---|---|---|
| 1 | 打开首页 | 首屏能不能看懂「这是干什么的」 |
| 2 | 允许摄像头 | 授权提示是否说得清 |
| 3 | 看加载过程 | 加载要多久？有没有卡住？ |
| 4 | 站到镜头前 | 画面里能看到自己吗？全身还是只有上半身？ |
| 5 | 依次做完八式 | 每式响了吗？该响的响了吗？ |
| 6 | 打开设置面板 | 摄像头/画面/语音的选项都看得懂吗？ |
| 7 | 刷新页面重来 | 记录还在吗？设置还在吗？ |
| 8 | 走完看记录页 | 打卡记录对不对？ |

## 三、每一步的具体操作与要记录什么

### 步 1 · 首页

**操作**：什么都不做，先看 3 秒。

**记录**：
- [ ] 3 秒内能明白这是干什么的吗？
- [ ] 「开始练」按钮够大够显眼吗？
- [ ] 拳种选择（八段锦 / 太极拳 / 五禽戏）看得懂吗？
- [ ] 有没有看不懂的字？

### 步 2 · 摄像头授权

**操作**：点「开始练」→ 出现授权弹窗 → 点「允许」。

**记录**：
- [ ] 弹窗出现得快吗？有没有人以为要点两次？
- [ ] 误点「不允许」后，页面有没有告诉你怎么补救？（Safari 要从地址栏左侧进去改）

### 步 3 · 加载

**操作**：什么都不做，等它加载完。

**记录**：
- [ ] 从点到出画面，几秒？
- [ ] 有没有「转圈一直转」的情况？
- [ ] 加载时有没有告诉你「在做什么」？（应该显示 4 个步骤）

### 步 4 · 取景（最关键的一步）

**操作**：退后 **2 米**，让**头顶到脚**都在画面里。

**记录**：
- [ ] 全身能看到吗？
- [ ] 左上角那行小字（`上半身 XX% · 下半身 XX% · 取景 XX%`）显示什么？
      **上半身要 >85%，下半身要 >60%**。不够就继续退后。
- [ ] 有没有骨架乱飞、乱跳的点？（正常：偶尔抖一下；不正常：某个点一直乱窜）

### 步 5 · 做八式

**操作**：按屏幕上显示的式名，依次做。每个式**保持 3 秒**。

八式顺序（就是屏幕上的提示）：

| 序 | 动作名 | 怎么算对 |
|---|---|---|
| 1 | 双手托天 | 双臂举过头顶，手掌相对 |
| 2 | 左右开弓 | 一手臂平举向侧，另一手屈肘像拉弓 |
| 3 | 单举 | 一手高举，另一手向下按到腰 |
| 4 | 转头后望 | **身体不动，只把头转向一侧** |
| 5 | 摇头摆尾 | 俯身深屈，**身体左右摆动** |
| 6 | 攀足 | 俯身向下，双手够向脚（**手别乱摆**） |
| 7 | 攒拳 | 马步站稳，一拳缓缓推出 |
| 8 | 背后七颠 | 两脚并拢，**脚跟起落 7 次** |

**记录（重点）**：
- [ ] 哪一式**该响没响**？记下式号
- [ ] 哪一式**不该响却响了**？记下式号和当时在做什么
- [ ] 第 4 式转头时，转到多少度才响？（听提示音的瞬间）
- [ ] 第 8 式要抖 7 次，会不会太累？节奏合理吗？

**看右下角**：
- 圆形 = 头是正对还是侧转（圆=正对，椭圆=侧转）
- 绿色=正对，橙色=侧转，红色=背对

**看左下角**：
- 头 / 身 的朝向显示
- 转身体时会显示「正在向左/右转身」

### 步 6 · 设置面板

**操作**：点右上角**齿轮**。

**记录**：
- [ ] 面板能打开吗？关掉齿轮能关掉吗？
- [ ] **摄像头**：能不能切换？（多数电脑只有 1 个）
- [ ] **取景比例**：9:16 / 3:4 / 1:1 / 跟随原始 —— 选哪个画面最舒服？（建议试 3:4）
- [ ] **分辨率**：切到 1280×720，画面会变清楚吗？会不会卡？
- [ ] **语音提示**：打开开关，听听声音
- [ ] **音量 / 语速**：语速调到 1.2 倍，会不会跟不上动作？
- [ ] 面板里有没有看不懂的词？（如「YAML」「WM」这类）

### 步 7 · 刷新

**操作**：在跟练页按 **F5** 刷新。

**记录**：
- [ ] 刷新后语音开关还开着吗？
- [ ] 刷新后摄像头设置（取景比例/分辨率）还在吗？
- [ ] 刷新后回到第几式？（应该是第 1 式）

### 步 8 · 记录页

**操作**：走完后点「退出」→「打卡记录」。

**记录**：
- [ ] 记录页显示了什么？看得懂吗？
- [ ] 「上次完成式数」「累计打卡」这些数字对吗？
- [ ] 缺什么信息？（比如：不知道练了多久、不知道练得标不标准）

## 四、遇到问题怎么报

### 记录格式（照这个填，发给聪哥）

```
【哪一步】例：步5 做第3式
【发生了什么】例：抬手举了 5 秒没响
【你在做什么】例：右手高举左手按腰，站直
【画面情况】例：左上角显示 上半身92% 下半身88% 取景22%
【期望】例：应该响
```

### 特别要留意的三个已知问题

1. **如果屏幕突然变黑/出现提示框** → 记下那一刻你在做什么（大概率是弯腰做式5/6）
2. **如果某式一直不响** → 试着把齿轮里的**「灵敏度」往左拖**（0.55 → 0.45），看会不会好
3. **如果画面只剩上半身** → 退后，不是 bug

## 五、附录 · 手机上怎么测

### 同一个 WiFi 下

1. 先在电脑上查 IP：运行 `ipconfig`，找 `IPv4 地址`
2. 手机浏览器输 `http://<那个IP>:5173`

**注意：手机上大概率打不开摄像头**（浏览器只在 https 或 localhost 下开放摄像头）。
需要 https 的话找聪哥拿证书，别自己折腾。

## 六、包里有什么

```
弦养-最终版交付包/
├─ 启动预览.bat        ← 双击这个
├─ 交付说明.md          ← 本文件
├─ 用户路径检查表.md    ← 打印出来，边走边勾
├─ 演示脚本.md          ← 给人演示时照着念，5 分钟讲完
├─ 源码/                ← 想改代码才看，不用管
│  ├─ src/              ← 全部源码（views / engine / data / culture / stores）
│  ├─ scripts/          ← 验证脚本（render / walk / 截图）
│  ├─ docs/             ← 设计文档
│  ├─ public/           ← 静态素材
│  ├─ package.json      ← 依赖与命令
│  └─ vite.config.js
└─ dist/               ← 网页本体（别改）
   ├─ index.html
   ├─ assets/          ← 打包后的 JS/CSS
   ├─ wasm/            ← 识别引擎（33MB）
   ├─ models/          ← 姿态模型（5.6MB）
   ├─ audio/ guqin/    ← 音色与琴谱音频
   ├─ art/ prot/       ← 美术素材与原型壳
   └─ ...
```

**注意**：`dist/` 里的东西**不要改**，改了会坏。只在浏览器里用就行。
想改代码改 `源码/`，改完在有 Node.js 的机器上跑 `npm install && npm run build`，再把新 `dist/` 覆盖回来。

**想跑源码版本**（可选，需要能装依赖）：

```
cd 源码
npm install
npm run dev        # 开发模式，改代码热更新
npm run test       # 跑全部自动验证（判定器 + SSR 渲染断言）
```
