命题三 · OPC时代身心疗愈 - 弦养 - 锻五音

# 弦养 · 以身为琴，以动为弦

> **做对一个动作，拨响一根古琴弦；练完一套八段锦，等于弹完一曲古琴。**

手机浏览器 H5 ｜ 无需安装 · 无需登录 · 无需后端 ｜ 摄像头姿态识别 × 古琴音疗

---

## 一、这是什么

**弦养**是一款手机网页（H5）身心疗愈原型。用户面对摄像头练习八段锦，系统用**本地姿态识别**实时判断动作是否达标；每做对一个动作，就拨响一根古琴弦，八式完成时**七弦齐鸣**——练完一套八段锦，就等于弹完一曲古琴。

产品方向为「**五音疗愈 × AI 动作识别**」的组合，对应命题三「OPC 时代身心疗愈」。

三个贯穿始终的设计决定：

- **本地优先**：姿态模型、识别 WASM、声音与练习记录全部在本地运行，**断网也能走完核心流程**；
- **身体即交互**：不靠点击触发，靠真实的身体参与换取即时可听见的声音反馈；
- **诚实的边界**：这是运动与音乐体验产品，**不提供任何诊断、治疗或医疗建议**。

### 2.2 文化内核如何数字化

弦养的文化内核是「**五音 — 五脏 — 八段锦**」。它被拆成**可计算、可播放、可校验的数据结构与契约**，而不是停留在文案：

**① 五音 → 可播放的定弦频率表**

| 弦 | 音名 | 频率 Hz |
|---|---|---:|
| 一弦 | 宫 | 174.61 |
| 二弦 | 商 | 196.44 |
| 三弦 | 角 | 220.89 |
| 四弦 | 徵 | 261.92 |
| 五弦 | 羽 | 294.66 |
| 六弦 | 宫（高） | 349.23 |
| 七弦 | 商（高） | 392.88 |

**② 八段锦八式 → 可测量的姿态判定特征**
把「招式」翻译成一组几何量：腕相对头肩的高度、双肘展开角、一侧伸展另一侧屈肘、头部转向与躯干稳定性、躯干俯身角与左右时序摆动、脚跟起落周期……再用 **33 点关键点 + 关节角 + 保持帧（约 300–500 ms）+ 每式锁存** 判定是否达标。

**③ 四层解耦：让「文化」不被写死进代码**

| 层 | 职责 | 数字化落点 |
|---|---|---|
| 音层 | 整段一个五音基调，负责氛围 | 音频基调参数 |
| 弦层 | 一至七弦，动作命中的即时声音 | `onHit(1..7)` |
| 势层 | 八式自身的升、降、开、合 | 动作判定器 |
| 解释层 | 文案 / 点单 / 路演中的五音五脏意象 | 内容数据 |

因此任意八式都能在任意五音基调下练习——**文化层与工程层互不绑架**。

**④ 五行五脏 → 文化编排锚点（非医学映射）**
二式商/肺、三式宫/脾、五式徵/心、六式羽/肾、七式角/肝，一/四/八式作起势·中段·收势骨架。这套关系只作用于**氛围、文案与叙事**，不改变「第几式对应第几弦」的技术契约，也不作医疗判断。

**⑤ 点 · 线 · 面三阶段 → 阶段音乐库**

| 阶段 | 形态 | 用户感知 |
|---|---|---|
| 一 · 学架子 | 点 | 一个动作一声，用户慢它就等 |
| 二 · 找气感 | 线 | 五声短句连成一条线 |
| 三 · 入静 | 面 | 约 12 分钟连续音乐弧线 |

**⑥ 视觉文化内核 → Design Tokens**
「宣纸白 / 墨黑 / 朱砂红 / 碧玉绿」等被沉淀为设计变量，**颜色即状态语义**（未命中=辅助灰，当前=朱砂红，已命中=碧玉绿），文化调性因此可被工程一致地复用。

### 2.3 如何「可插拔」接入硬件与场景

**架构上可插拔**——识别引擎、音乐引擎、推荐规则、存储服务与 UI **彼此分离**，只通过统一契约通信：

- 识别侧只负责产出 **`onHit(stringIndex)`** 事件；
- 音频侧只消费 `onHit`，**不关心动作信号从哪来**（真实识别 / 预录兜底 / 手动触发可互换）；
- 任何新的输入源（体感手柄、可穿戴 IMU）或输出源（音箱、香薰机、灯带）**只需实现同一契约即可接入，核心链路一行不改**——这就是「可插拔」的工程含义。

**接场景**：现场路演 · 康养与养老机构 · 家庭客厅大屏 · 健身房与瑜伽馆 · 文旅与酒店 · 中医馆与社区教学。因**本地优先、零后端**，尤其适合弱网、离线与私有化部署的场景。

**接硬件（扩展点，非现状）**：摄像头是当前唯一输入。向外延伸时，可在事件总线后挂一层适配器——
- 输出侧可接：智能音箱 / 古琴音箱（音频）、**智能香薰控制 API**（香方 → 扩香节奏）、氛围灯、中控屏；
- 通过 **WebSocket / HTTP 适配层**把 `onHit`、阶段切换、整套完成等事件广播给上述设备。

> 这些**接口位已预留、尚未实现**。我们给出的是一套**可插拔的架构与契约**，而不是「已经对接了香薰机」的既成事实。

## 三、核心体验：八式 × 七弦

八段锦 8 式 × 古琴七弦：前 7 式各触发一弦，第 8 式「背后七颠百病消」触发**七弦齐鸣**。

| 式序 | 招式 | 弦层反馈 |
|---|---|---|
| 1 | 双手托天理三焦 | 一弦 |
| 2 | 左右开弓似射雕 | 二弦 |
| 3 | 调理脾胃须单举 | 三弦 |
| 4 | 五劳七伤往后瞧 | 四弦 |
| 5 | 摇头摆尾去心火 | 五弦 |
| 6 | 两手攀足固肾腰 | 六弦 |
| 7 | 攒拳怒目增气力 | 七弦 |
| 8 | 背后七颠百病消 | 七弦齐鸣 |

七弦进度视觉：未命中为辅助灰，当前式为朱砂红闪烁，已命中为碧玉绿，第 8 式七个点同时亮起。

## 四、用户路径

| 步 | 用户动作 | 屏幕反应 |
|---|---|---|
| 1 | 打开网址 | 正中一个大按钮「开始练」 |
| 2 | 点击并授权摄像头 | 实时画面 + 33 点人体骨架跟随 |
| 3 | 做「双手托天理三焦」 | 动作到位 → 弦位亮起 + 一声古琴响 |
| 4 | 依次做完八式 | 第 8 式 → 七弦齐鸣 →「一曲完成」 |
| 5 | 查看总结 | 得分、琴谱可视化、练习时长与命中数 |
| 6 | 回首页 | 能翻到今天的打卡记录 |

## 五、技术架构

| 层 | 选型 |
|---|---|
| 前端工程 | Vite 6 + Vue 3.5 + vue-router 4 |
| 姿态识别 | `@mediapipe/tasks-vision` Pose Landmarker Lite（33 点关键点） |
| 模型 / WASM | 本地 `pose_landmarker_lite.task` 与本地 vision WASM，**不依赖运行时 CDN** |
| 动作判定 | 关节角度 + 关键点关系 + 保持帧（约 300–500 ms）+ 每式锁存 |
| 音频 | 真实古琴散音采样（Web Audio） |
| 存储 | `localStorage` 本地打卡记录，读写均做容错 |
| 服务 | Node 内置 `http` 零依赖静态服务 |

```text
手机浏览器
  ├─ Vue 页面与路由
  ├─ 摄像头 MediaStream
  ├─ MediaPipe Pose Lite + 本地 WASM / 模型
  ├─ 姿态判定器（保持帧 + 锁存）
  ├─ onHit(stringIndex) 事件        ← 可插拔的对外契约
  ├─ 古琴单音 / 和声播放
  ├─ localStorage 本地记录
  └─ 预录视频兜底（识别失败 ≤ 3 s 切换）

本地静态服务（server.cjs，零依赖）
```

**音频契约**：`onHit(stringIndex)`，`stringIndex` 取 1–7，第 8 式传 `'choir'`（七弦齐鸣）。这是「五音疗愈音频能力」对外的稳定接口，也是外界接入弦养的最小切面。

## 七、快速开始（直接运行构建产物）

只需 Node.js（LTS 版即可，无需安装任何依赖）：

```bash
node server.cjs 5173
```

浏览器打开 `http://localhost:5173` 即可体验。

> **摄像头权限**：浏览器仅在 `https` 或 `localhost` 下开放摄像头。电脑本地用 `localhost` 即可；手机真机演示需走 HTTPS（见 `train/README.md` 与 `train/docs/手机访问指引.md`）。

## 八、源码开发（跟练子应用 `train/`）

```bash
cd train

export NODE_OPTIONS=""            # 本机必须：否则文件删除被 safe-delete 拦截
npm install --ignore-scripts      # 本机必须：否则 esbuild postinstall 回滚 node_modules

npm run dev            # http://0.0.0.0:5173   —— 电脑本机调试
npm run dev:https      # https://0.0.0.0:5174  —— 手机真机演示走这条
npm run build && npm run preview

npm run test:all       # 判定器 / 渲染 / 音色 / 兜底 / 净化器等自测
```

构建产物接入站点子路径：

```bash
cd train
./node_modules/.bin/vite build --base=/s4/
rsync -a train/dist/ dist/s4/     # 同步到站点
```

## 十、设计与安全边界

**刻意没有的东西**（是设计决定，不是没做完）：

- 没有后端、数据库、登录、云同步、CDN；
- 没有实时逐句动作纠错，没有第二套可识别拳种。

**非医疗声明**：

- 弦养是运动与音乐体验产品，**不提供诊断、治疗或医疗建议**；
- 五行五脏内容用于**文化意象、氛围与编排叙事**，不作为医疗判断；
- 界面不展示「你肝不好」「入脏」等诊断式表达；
- 身体数据与姿态关键点**只在当前设备本地处理，默认不上传、不保存视频**，且可随时删除。
