# DESIGN · 弦养 产品介绍

> 风格来源：不命中 academic / consulting / redgold 三个预设分支（产品介绍属通用场景）→ 走通用设计原则。
> 色板依据**产品自身视觉风格**推导：从主壳产物 `dist/app.css` 提取的真实用色为暖宣纸米 + 赭石 + 青瓷玉 + 暖金（`#FDF9EF / #B0552E / #6E8F7C / #C9A97E`），本设计据此实例化，忠于产品气质。

## 1. 画布与母版

- 画布：**1280 × 720**（16:9）
- 页面 padding：上 20 / 下 20 / 左右 72
- 三分区母版（内容页统一）：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px | 页主标题 36px（宋体 bold）；右上 40×40 朱砂方印（L3，全篇同位） |
| **B · 内容区** | 120–660px | 540px | 全部正文 / 表格 / 图 / 图示；禁止挤占 A/C |
| **C · 页脚条** | 660–720px | 60px | 左：`弦养 · 以身为琴，以动为弦`；右：`NN / 12`，统一 14px |

- 封面 / 结尾页采用自定义版式（省略 A/C 三区结构，保留页脚页码）。

徵·火·心 `#B0552E` ｜ 角·木·肝 `#5F8A72` ｜ 宫·土·脾 `#C9A97E` ｜ 商·金·肺 `#A79E8C` ｜ 羽·水·肾 `#4E6E7E`

### 色彩面积分配（页面映射见 §6）
- **Hero 页**（P1/P5/P10）：主色 55–65%，强调色 15–20%（金调爆发），辅色 ≤ 20%
- **Supporting 页**（其余）：主色 50–55%，辅色 18–25%，强调色 ≤ 10%
- 全篇节奏：3 页深调（P1/P5/P10）+ 7 页浅调，避免每页比例雷同。

### 渐变与半透明
- 深页底：`linear-gradient(160deg, #241C14 0%, #15100B 100%)`
- 金调高光（仅金句/巨型数字/印章）：`linear-gradient(135deg, #C9A97E 0%, #B0552E 100%)`
- 浅页卡片面：`rgba(242,231,210,0.75)`；深页卡片面：`rgba(255,246,230,0.07)`
- 主视觉上的文字蒙版：`rgba(24,17,11,0.55)`，自承载文字一侧向另一侧渐隐
- 卡片浮起：`boxShadow: '0 10px 30px rgba(60,40,20,0.10)'`

## 4. 信息密度门禁

- 常规内容页留白 ≤ 35%（本片按 18–30% 控制）
- 每页 ≥ 1 个视觉锚点（≥ 44px 元素 或 ≥ 40% B 区主视觉）
- 卡片填充率 ≥ 85%；横向兄弟卡三段（标题/正文/尾条）等高对齐
- 正文页不使用全屏背景图；大图以独立组件出现（占 50–60% 宽/高），四周保留页底色

## 7. 动态效果规划（PowerPoint 放映时播放）

原则：单页 ≤ 4 个动画，全篇统一 `fadeIn` / `flyIn` 家族，duration 400–800ms，delay ≤ 500ms；装饰、页脚、页码不加动画。

| 页 | 动效设计 | animType | startType |
| :--- | :--- | :--- | :--- |
| P1 封面 | 标题 fadeIn → 副标 fadeIn → 落款 fadeIn（四拍递进） | fadeIn / flyIn | afterPrevious 串行 |
| P2 概述 | 巨型五音 flyIn(自右) → 判断段落 fadeIn | flyIn / fadeIn | afterPrevious |
| P6 点线面 | 三幕环整体 zoom → 底部三卡 fadeIn | zoom / fadeIn | afterPrevious |
| P7 声音 | 左卡 fadeIn → 三种听感 fadeIn → 频率算式 fadeIn | fadeIn | afterPrevious |
| P9 场景 | 大图 fadeIn → 右侧标签组 fadeIn | fadeIn | afterPrevious |
| P12 结尾 | 金句 fadeIn → 落款 fadeIn → 印章 pulse | fadeIn / pulse | afterPrevious |

（P3 / P4 / P5 / P8 / P10 / P11 保持静态：P4、P10 为表格 / chips 信息页，加动画会拖沓；保证"高级"来自克制的节奏而非每页乱动。）
