## 格式

`ogg Vorbis q3` / 单声道 / 44.1 kHz，7 个共 **80 KB**（等效 wav 605 KB，mp3 89 KB）。

**为什么不用 mp3**：mp3 的 pre-echo 恰好吃掉拨弦冲激，而起音冲激（0–4 ms 谱重心
真实为 2401 Hz）正是古琴辨识度的关键。ogg Vorbis 在同码率下对瞬态与噪声的损伤明显更小。

## 音色特征（标定结论）

分音为**整数倍谐波**（1~12 次全部存在），基频反而是最弱一档（平均 −22 dB，
中高次谐波比基频强 14 dB）——这是共鸣箱压住基频的结果。

**辨识度主要来自琴体共振**：456.9 / 392 / 261 / 130.5 Hz 出现在**全部 7 个音**里，
偏差 <1 Hz，且相对各音基频的序号随音高递减 → 频率与弦无关，是共鸣箱模态。

真实衰减率 −15.6 dB/s（−6 dB 用时 0.344 s）。

## 注意：素材未经增益补偿

原始各音峰值不齐（−14 ~ −19 dBFS），已统一归一到 **−3 dBFS**。
播放端不再做额外衰减，交给 `guqin.js` 的 `master` 总线统一控制。
