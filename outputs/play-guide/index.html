弦养 · 本机跑起来怎么玩

已经在无头浏览器里把下面每一步都真跑过一遍：0 报错，教练小人、摄像头识别画面、打卡流程全部正常。你照做即可。

一、起来（两步）

方式 A · 双击（推荐）

在访达里打开 /Users/leo/WorkBuddy/疗愈，双击 启动预览.command。会自动起服务并打开浏览器；关掉那个终端窗口即停止。

方式 B · 粘一行命令（若双击被系统拦）

cd /Users/leo/WorkBuddy/疗愈 && node scripts/preview-all.cjs 5400

然后浏览器打开 http://127.0.0.1:5400/。停止：在该终端按 Control-C。

为什么必须你来点这一下：这台机器上，我启动的后台进程在每次操作结束后都会被回收（已实测两次，交给 macOS 的 launchd 托管也被权限拦下），所以服务没法从我这边常驻。你用自己的终端跑，它就一直是活的。

三、玩一遍的完整动线（实测截图）

  1. 打开 /，等加载页出现，点「进入弦养」。
  2. 问诊 7 题：每题先点一张卡，再点「下一题」（不选会提示「请选择一项后再继续」）。
  3. 落到首页（今日 · 节气 / 今日推荐）。
  4. 想看听的部分 → 底部「音疗」；想练 → 「开始练」进引导页，选模式（全套 8 式 / 招牌 3 式）与阶段（点 / 线 / 面）。
  5. 点「开始动作预览」→ 跳到真正的跟练页 /s4/#/train。
  6. 跟练页：左上教练小窗循环示范，右侧是你自己的摄像头画面。**判定闸门**——动作做到位才进下一式，没通就一直练这一式（点「跳过本式」可手动过）。

四、两个必知的小事

  • 摄像头：跟练页首次进入浏览器会问权限，点「允许」。不想开也能用——页面上有「点一下也算响（摄像头不可用）」的兜底按钮。
  • 声音：浏览器不允许自动播放，进页面后点一下任意播放/琴弦才会响。音疗页列出的曲子都是真有干净音源的。
