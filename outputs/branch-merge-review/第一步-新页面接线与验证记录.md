### 改动 1：`train/src/main.js`
- 新增 3 条 **lazy 路由**（`() => import(...)`，各自产出独立 chunk，不进主包）

## 四、为什么没重建 `dist/s4`

当前工作区源码含**你的在制改动**（`TrainView.vue`、`HomeView.vue`、`DemoAnimation.vue`、`records.js`、`package.json`）。
现在跑 `vite build` + `rsync` 会把这些 WIP **一并打进产物**，那才是真正会改动前端外观的操作。
所以本次所有构建均输出到 `/tmp`，`dist/` 一个字未动。

要让线上 s4 真出现这三个新页面，需在**你的 WIP 定稿后**再重建：
```
cd train && ./node_modules/.bin/vite build --base=/s4/
rsync -a train/dist/ dist/s4/     # 注意：不要加 --emptyOutDir
```
