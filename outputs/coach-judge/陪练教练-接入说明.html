弦养 · 跟练识别页（s4）· 交付说明

陪练教练接入项目应用
「教练与摄像头同时开 · 没通关就一直练这一式」

把独立页面里的陪练教练接进真正的项目应用 train/（Vue3 + Vite + 真实 MediaPipe），并把「什么时候进下一式」改由判定器决定。

gate = judge（判定闸门，默认） 端到端 20/20 状态机单测 26/26 2026-10-04

「他与视频摄像头都打开，他们可以同时进行……动作没通关，此动作会一直循环；动作通关，就进入下一个动作。」

—— 这一句里的「循环」和「推进」原本是互斥的：原实现是「超时兜底放行」，等够 25 秒就自动进下一式。本轮把推进权从计时器交给判定器：没通关就永不换式，通关才往前走。

01现在怎么跑

教练默认开启，不需要点任何开关。主壳（9 页设计稿那套）里点「开始跟练」就会落到这个页面，参数由主壳给出。

# 起服务（仓库根目录，端口自选）
node server.cjs 5399

# 主壳入口（点「开始跟练」实际跳的就是这个地址）
http://127.0.0.1:5399/?screen=home
#   → /s4/#/train?stage=1&mode=full&style=baduanjin&tone=gong

# 直接进跟练页
http://127.0.0.1:5399/s4/#/train?mode=full&style=baduanjin&tone=gong

# 临时关掉教练（回到原来的「纯判定跟练」）
http://127.0.0.1:5399/s4/#/train?mode=off

02两种闸门：谁决定「什么时候进下一式」

这是本轮唯一的语义分叉，做成预设里的一个字段 gate，而不是两摊各改各的代码。

gate = judge（判定闸门 · 本轮的默认）gate = time（计时闸门 · 旧行为）
何时进下一式只有判定命中硬上界到点就放行
没通关时永远停在这一式，示范循环陪练25s → 宽限 8s → 自动跳式
宽限期没有（永不进入 grace）有，还能点「再练一会儿」续期
没通关期间在做什么每 15s 发一次 nudge：重播一遍示范 + 轮次 +1，仍留在跟练、仍接受命中重放一次示范（有额度）
兜底靠什么手动出口（教练条里的「跳过本式」）计时本身就是兜底
用途真实训练：这个动作做不对就继续练这个动作走流程 / 教学演示 / 无人值守；现在只用于 A/B 反证
 
begin(idx) → demo ──demoDone() / demoMaxMs 保底──→ follow
                                                    ├─ hit(idx)      → done → advance
                                                    └─ attemptMs     → nudge（重播示范 + 轮次+1，留在 follow）
                                                       ↑ 判定闸门到此为止，永不进 grace、永不 advance

「一直循环」≠「停死」——为了让人一眼看出系统还活着，判定闸门同时给足三条证据：① 每轮都重播示范，画面一直在动；② 教练条上显示「第 N 轮陪练」；③ 常驻「跳过本式」按钮作为唯一主动出口。

05现场可调参数

全部走 URL query，改完刷新即可，不用重新打包。这也是端到端测试能把节奏压到十几秒的原因。

参数生效范围说明
?mode=full|short|off全局完整 / 精简两档节奏；off 关闭教练，回到纯判定跟练
?coachGate=time全局切到计时闸门（对照实验用）
?coachAttempt=秒判定档跟练每几秒重播一遍示范（默认 15s）
?coachSim=秒判定档仅演示 / 验证：跟练停留 N 秒后模拟一次通关。默认不参与
?coachDemo=秒两档示范阶段的保底时长（示范动画缺帧时不至于卡在示范）
?coachSoft= ?coachHard= ?coachGrace= ?coachRedemo=计时档旧三段式的三个等待 + 重放额度

06已知边界

判定阈值没动

仍然沿用原来的 threshold 0.55 / 保持帧 10。判定太严导致用户做对了也不响是目前唯一可能让人「真的卡住」的点，需要现场真机体验后微调，本轮刻意不动。

「跳过本式」仍是必要的

判定闸门没有计时兜底，所以这个手动出口不能省。它同时兼「身体不适」「摄像头取景不对」的退路。

预录兜底期间教练会暂停

摄像头彻底挂掉切到预录视频时，教练计时整体暂停（否则两条推进互相打架），此时由预录自带保险计时接管。

主壳指标卡仍是硬编码

顶部「上半身 92% / 下半身 88% / 取景 92%」是设计稿复刻的静态值，与真实识别无关。属前端冻结期的遗留问题，只记录不改。
