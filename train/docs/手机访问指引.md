## 一、地址与端口（记死）

| 用途 | 命令 | 地址 |
|---|---|---|
| 电脑本机调试 | `npm run dev` | `http://localhost:5173` |
| **手机演示（唯一走这条）** | **`npm run dev:https`** | **`https://192.168.1.209:5174`** |
| 看生产构建 | `npm run build && npm run preview` | `https://192.168.1.209:4173` |

> ⚠️ **绝对不要发 `http://192.168.1.209:5173` 给手机**：非安全上下文，
> `getUserMedia` 会被**直接拒绝**，表现是「点开始练 → 摄像头没反应」。

## 二、开之前确认三件事

1. **同一个 WiFi**。电脑的 WLAN IPv4 是 `192.168.1.209`（换网络一定会变，变了就重查）。
2. **没开 VPN / 代理**。开了会导致手机连不上电脑（代理走本机回环）。
3. **`npm run dev:https` 真的在跑**（不是 `npm run dev`）。

查电脑 IP：

```bash
node -e "const os=require('os');const n=os.networkInterfaces();
for(const k in n)for(const a of n[k])if(a.family==='IPv4'&&!a.internal)console.log(k,a.address)"
```

## 三、iPhone（iOS）必过的两道坎

iOS 是最容易翻车的，Android 一般都直接放行。

### 坎 1 · 装根证书

```bash
# 手机上打开这行（电脑和手机同 WiFi 时）
https://192.168.1.209:5174/setup-cert.html
```
页面里有全套可视化的装证书流程图（截图见 `evidence/setup-cert-mobile.png`）。

也可直接把 `xianyang/certs/装这个到手机.crt` 发到手机（AirDrop / 微信文件传输助手），
点开即装。

### 坎 2 · **装完还要手动信任**（90% 的人栽在这一步）

> 设置 → 通用 → **关于本机** → 证书信任设置 → 打开你装的那个 rootCA 的开关。

**装了但不信任，Safari 照样弹「无法验证服务器身份」** —— 这不是页面坏了。

> 为什么不用 `@vitejs/plugin-basic-ssl` 的自签名：`vite.config.js` 里已经改成
> **优先读 `certs/server.crt` + `server.key`（自建 CA）**，只有它不在时才退回
> basic-ssl（而 iOS Safari 会拒绝自签证书）。

## 四、Android

一般直接访问 `https://192.168.1.209:5174` 就行；若系统提示「证书不受信任」：
进入系统「安全 → 加密与凭据 → 从存储设备安装 → CA 证书」，装 `certs/rootCA.crt`，
之后浏览器会放行。

## 五、D10 四人截图收集清单

每个人各交 **一张截图 + 三行信息**，文件名 `evidence/d10-<名字>.png`：

```yaml
- 名字: <甲>
  机型: iPhone 13 / 型号
  系统: iOS 17.x
  浏览器: Safari
  入口: https://192.168.1.209:5174
  截图: evidence/d10-甲.png
  结果: ✅ 能开 / ❌ 卡在哪一步（写弹窗原文）
```

|---|---|---|---|---|---|---|
| 1 | 甲 | | | | `d10-甲.png` | ☐ |
| 2 | 乙 | | | | `d10-乙.png` | ☐ |
| 3 | 技术甲 | | | | `d10-技术甲.png` | ☐ |

### 交回的标准（三选一都算过）

- **✅ 最理想**：首页 → 点「开始练」→ 授权 → 出画面 + 骨架的**连续三张**；
- **✅ 及格**：停在跟练页且**能看到摄像头画面 + 白色骨架**的一张；
- **❌ 不算**：只拍到「无法访问此网站」或证书警告页的（那是没过，不是证据）。

### 卡住了按这个顺序排

| 现象 | 先查 |
|---|---|
| 「无法访问此网站」/ 连接被重置 | 电脑的 `dev:https` 还活着吗？同 WiFi 吗？VPN 关了吗？ |
| 「无法验证服务器身份」 | iOS：**证书信任设置打开了吗**（第三节坎 2） |
| 页面出来了但点「开始练」没反应 | 走的是 `http` 不是 `https` 的 **局域网 IP** |
| 能开但骨架不出 | 光线 / 站位（见 `真机实测记录.md` P3/P4），或距离太近 |
| 电脑上明明能开 | 手机 IP 变了（换网/休眠后 DHCP 重分配），重查 IP |
