# 手机端访问指南（iPhone / Android）

> 一句话：**不能把 `localhost` 发给手机**，要用电脑的局域网 IP，且必须是 `https`（否则手机不给摄像头权限）。

---

## 一、为什么要 https

手机浏览器只在**安全上下文**里开放摄像头：

| 访问方式 | 是否安全上下文 | 摄像头 |
|---|---|---|
| `http://localhost:5173` | ✅（仅本机） | 可用，但**只有电脑能访问** |
| `http://192.168.1.209:5173` | ❌ | **被拒绝** |
| `https://192.168.1.209:5174` | ✅ | **可用** ✅ |

所以手机必须走 `https://192.168.1.209:5174`。

---

## 二、前提：手机和电脑在同一个 WiFi

手机连的必须是**和电脑同一个路由器**。如果电脑用网线、手机连 WiFi，通常没问题；但如果电脑开了 VPN/代理，手机可能访问不到。

验证：手机浏览器打开 `https://192.168.1.209:5174`，能出页面就说明网络通。

---

## 三、iPhone（iOS Safari）

iOS 对证书最严格，必须**先装根证书并信任**，否则页面直接打不开。

### 步骤 1 · 把根证书传到手机

方式 A（推荐，AirDrop / 微信文件传输助手）：
1. 电脑上文件位置：`xianyang/certs/rootCA.crt`
2. AirDrop 给手机，或用微信「文件传输助手」发给自己
3. 手机上点开这个文件，会提示「已下载描述文件」

方式 B（不用传文件）：
1. 电脑上起一个 http 服务把证书暴露出去，手机访问下载：
   ```bash
   cd xianyang/certs
   python -m http.server 8000
   # 手机浏览器打开 http://192.168.1.209:8000/rootCA.crt 下载
   ```
2. 下载完记得关掉这个临时服务

### 步骤 2 · 安装描述文件

手机：**设置 → 通用 → VPN与设备管理 → 安装已下载的描述文件** → 点右上角「安装」

### 步骤 3 · **信任证书（关键，别漏）**

手机：**设置 → 通用 → 关于本机 → 证书信任设置** → 找到 `Xianyang Dev Root CA` → **打开开关**

> ⚠️ 不做这一步，Safari 依然会拒绝。

### 步骤 4 · 打开网站

Safari 输入：`https://192.168.1.209:5174`

### 步骤 5 · 允许摄像头

首次点「开始练」会弹「此网站想访问摄像头」→ 选**允许**。

如果误点了「不允许」：Safari 地址栏左侧的「aA」图标 → 网站设置 → 摄像头 → 改为「允许」。

---

## 四、Android（Chrome）

比 iOS 简单，通常**不需要装证书**：

1. 手机浏览器打开 `https://192.168.1.209:5174`
2. 提示「您的连接不是私密连接」→ 点**高级**→ **继续前往**
3. 点「开始练」→ 允许摄像头

若仍不行，用方案 B 的证书方式，或换 Firefox 试试。

---

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面打不开（网络错误） | 手机不在同一 WiFi | 确认同网段；关电脑 VPN |
| 页面一直转圈 | 证书不受信 | iOS 必做「步骤 3 信任证书」 |
| 提示「需要 https」 | 用了 http 访问 IP | 换成 `https://` + 5174 端口 |
| 摄像头画面黑/无权限 | 没授权 | 地址栏图标 → 网站设置 → 摄像头允许 |
| 画面出来了但看不到腿 | 站得太近 | 退后 2 米（实测：退后后踝 visibility 从 0.09 升到 0.90） |

---

## 六、如果 IP 变了

电脑 IP 可能因重连路由器而变化。查当前 IP：

```bash
ipconfig | findstr IPv4
```

变了就重新生成证书（IP 写进证书的 SAN 里）：

```bash
# 先改 scripts/gen-cert.sh 里的 IP= 变量
bash scripts/gen-cert.sh
# 重启 dev:https
```

## 七、彻底免证书的替代方案

如果嫌证书麻烦，有一个不用 https 也能开摄像头的办法 —— **内网穿透**：

```bash
# 用 cloudflared 把本地服务暴露成公网 https 域名
cloudflared tunnel --url https://localhost:5174
```

会得到一个 `https://xxx.trycloudflare.com` 地址，**手机浏览器直接开，证书是真证书，无需安装**。

代价：需要外网（断网就用不了），且演示时有公网流量。

**建议**：演示当场用这个（省事），日常开发用上面的证书方案（离线可用）。
